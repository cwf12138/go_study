# 随手收藏

用于常用网站、稍后读文章、工具和资料入口。左侧“记录”分组打开“随手收藏”，粘贴网址即可保存；标题留空时使用域名，文件夹留空时进入“未分类”。不抓取远程标题、缩略图或网页正文，不需要外部 API。

## 日常操作

- 输入文件夹名称即可分类，无须先建立目录。只有包含条目的文件夹会显示。
- 全部 / 置顶 / 稍后读 / 回收站视图，叠加文件夹、关键词筛选和排序。每页 12 条，始终置顶优先；搜索范围含标题、网址、备注和文件夹。
- 点击标题在新标签页打开原网页；不会自动标记已读，可手动切换已读/待读。
- 删除进入回收站，可恢复；不提供永久删除。恢复时若同网址已经存在，会提示冲突，不覆盖记录。
- “导出”将**当前筛选下所有页**的链接和备注生成浏览器可导入的 HTML 书签文件；不保留文件夹层级、已读或置顶属性。完整数据可使用平台个人 JSON 导出。

## 保存与安全

记录按账号存储，接入现有周期快照与正常退出保存；不是每次点击后同步落盘。每账号最多 3000 条（含回收站）。旧快照未包含 `bookmarks` 字段时按空收藏架读取，不改动已有模块的数据。

同 ID / 版本 / 内容原样重试幂等；版本冲突不会静默覆盖。服务器使用写锁检查重复网址，统一域名大小写和空根路径，保留查询参数与片段，不声称识别不同跟踪参数下的同一文章。

网络失败导致保存结果不确定时，编辑与其他写入暂时锁定。可关闭编辑窗口，使用“原样重试”；也可先导出草稿，再“重新核对”读取服务器状态。冲突或校验失败保留表单输入，用户可复制后刷新重新编辑。

只允许 HTTP/HTTPS 链接，不允许 URL 用户名密码。服务端不访问收藏网址；打开链接是用户主动操作。没有后台链接可达性检测或网页离线阅读。请勿存放含访问令牌的私密 URL；快照、导出文件和草稿未加密，请妥善保管。

## 部署与验证

重启 Go 服务并刷新页面，无需配置环境变量。新增接口：`GET /api/v1/bookmarks`、`PUT /api/v1/bookmarks/{id}`，需要登录。

- `go test ./...`：输入校验、幂等、冲突、并发去重、用户隔离、快照往返和个人导出。
- `node tools/bookmarks_ui_smoke.cjs`：DOM 引用、弹窗、未知保存结果重试、分页筛选、账号切换和输出转义。
- 浏览器自动化环境未提供可用实例，本次未完成真实截图验收。人工建议在桌面、手机宽度及夜间主题下检查；添加一条链接、编辑分类、标记已读、回收及恢复，重启后确认记录仍在。
