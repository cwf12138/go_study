# 物品管家

入口：左侧「记录 → 物品管家」，也可 Ctrl/⌘ K 搜索。更新后重启 Go 服务并刷新页面，无需新增配置。

## 使用

- 收录物品只需名称、分类和数量；收纳位置、购入总价、购入日期、保修截止、到期日期和备注均可选。支持自定义分类。
- 填写借用人即表示借出，可以选填预计归还日期；列表点击“确认归还”清空当前借用人和归还日期。当前不保留借用历史。
- “需要关注”包含 30 天内到期、保修结束或预计归还的记录，也包含已经超过这些日期的记录。按设备当地日期计算；到期当天不是逾期。每件物品只在概览计数一次，但可以展示多个提示。
- 支持名称、位置、分类、借用人及备注搜索；分类/状态筛选；最近更新、名称、价格和最近到期排序；每页 12 条。
- 已借出的物品必须先确认归还才能归档。归档可恢复，所有概览均不含归档；总价是登记购入成本，不是市场估值，也不会自动同步生活账本。
- CSV 导出当前全部筛选结果（不限当前页）。草稿可以导出 JSON 留档，当前没有草稿导入功能。文件可能包含私人备注、收纳位置和借用人，请妥善保存。

## 数据与失败处理

- 所有记录按账号隔离，纳入现有周期 JSON 快照和个人数据导出。每账号最多 1000 条（含归档），单条数量 1–9999；金额使用整数分，购入总价最多一亿元。
- 保存采用版本校验。冲突不会覆盖另一窗口的内容；草稿保留在编辑器，可先导出，然后关闭并刷新重新编辑。
- 网络超时可能已保存成功，请原样重试。同一 ID、版本及内容的重试不会重复创建；修改未知结果的草稿后重试可能提示版本冲突。
- 页面关闭或刷新时未保存草稿只提供离开警告，不承诺自动恢复。关闭弹窗前会询问是否放弃修改。退出或切换账号会清除页面草稿。
- 本模块不提供后台推送、邮件通知、附件上传、识图、保修承诺或多人共享。提示仅供整理生活，不应替代保质期包装、厂商保修条款等真实依据。
