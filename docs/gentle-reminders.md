# 轻提醒：饮水与起身活动

从任意功能页的顶部点击「轻提醒」。这是常驻的小工具，不增加侧栏页面，也不会强制中断正在做的事。更新代码后须**重启 Go 服务并刷新网页**，因为前端资源嵌入 Go 二进制。

## 开始使用

1. 展开「调整提醒节奏」，按需要修改饮水和活动间隔（5–180 分钟），也可以只开启其中一种。
2. 点击「保存设置」，再点「开始 / 继续」。默认关闭计时，不会自动申请通知权限。
3. 到时间时，右下角出现非模态小卡片，顶部显示待处理数量。打开轻提醒面板时不重复显示右下角卡片。
4. 「喝过了 / 活动过了」记录一次手动确认，并从现在重新计时。可以在还没到时间时提前确认；暂停状态下也可记录，但不会自动恢复计时。
5. 「稍后提醒」延后 5、10 或 15 分钟（可保存偏好）；「跳过」从现在开始下一轮。这两项都不增加次数。

饮水和活动是两个独立计时器，不会因其中一个完成而重置另一个。只修改发生变化的间隔或开关会重置对应计时，其余设置不重置计时。暂停全部保留剩余时间，继续后接着计时；暂停前已经到点的提醒会在继续后显示。

界面采用两张蓝灰 / 鼠尾草绿卡片，大字倒计时、进度提示、顶部简短状态、今日确认次数与记录。支持深色模式、手机两列 / 极窄屏单列、键盘操作、原生对话框 Esc 关闭与减少动态效果偏好。不抢输入焦点，不发出声音。

## 动效与操作反馈

参考 Apple HIG 的 [Motion](https://developer.apple.com/design/human-interface-guidelines/motion) 和 [Feedback](https://developer.apple.com/design/human-interface-guidelines/feedback) 原则，将动效用于开合关系、状态变化与操作确认，不添加持续闪动或每秒翻滚的数字。

- 弹窗使用 280ms 的轻微位移 / 缩放入场、170ms 退场；手机采用靠近底部的面板布局。快速操作可取消旧动画，Esc 与关闭按钮使用相同路径，关闭后返回原入口的键盘焦点。
- 提醒卡片轻柔进入；确认或稍后提醒后退出。同时出现两种提醒时只移除对应一项，另一项的 DOM 和键盘焦点保留。退场内容立即退出可交互状态，不会让按钮在淡出期间被重复点击。
- 设置 / 记录区平滑展开，可快速反向收起。开关滑块、常用间隔选中态、±5 分钟按钮与边界禁用状态，帮助识别当前选择；仍可直接输入任意 5–180 的整数。
- 完成、暂停、继续、稍后与保存都有可见的文字反馈。完成时图标 / 今日次数仅反馈一次，不影响计时规则，不因动画修改记录或截止时间。
- 进度提示改用 transform，避免每秒改宽度触发布局。动画逻辑独立在 `gentle-reminders-motion.js`，使用可取消的 Web Animations，处理取消后的 Promise 拒绝，不引入动画依赖。
- 系统开启「减少动态效果」时立即完成正在执行的动画，后续切换直接生效；页面隐藏时也立即收束动画。无 Web Animations 支持时降级为即时切换。退出 / 切换账号及存储错误清理不等待退场动画，避免私有内容残留。

这是网页端交互优化，不模拟系统触觉反馈，不主动播放声音，也不承诺与原生 iOS / macOS 相同的渲染表现。

## 专注联动和免打扰

- 默认启用「专注时，先不打扰」：计时继续，到点后等待当前专注暂停、进入中场休息或结束；不会暂停专注计时器，也不会修改专注完成记录。
- 读取同一浏览器里现有专注状态，校验账号、阶段、运行状态与阶段截止时间。不跨设备监测，也不在过期阶段上无限等待。专注状态持久化后通过 `daynest:focus-changed` 通知本模块；每秒检查和跨标签页 storage 事件作为补充。
- 可设置每天的可提醒时段，采用设备的当地时间（不是固定北京时间），支持如 22:00–07:00 的跨午夜时段。开始和结束不能相同。时段外倒计时继续，但不弹提示；进入时段后显示至多一条饮水、一条活动的待处理提醒。
- 未处理的提醒一直保留，不会每隔几分钟反复弹出，也不会因关闭设置面板自动记为完成。长时间休眠后不回放漏掉的每一轮。

## 系统通知与浏览器限制

默认仅在网页内提示。主动点击「开启系统通知」才会申请权限；被拒绝时保留网页内提醒，不循环申请。关闭系统通知不会改变浏览器的权限设置。

系统通知需要 HTTPS / localhost、Notification API 和 Web Locks。页面在后台运行时会尽力发出无声通知；前台仅用网页卡片。OS 勿扰、浏览器节流、设备休眠可能使通知延迟或不显示。点击系统通知会尝试返回提醒面板，不直接计为完成。

Web Locks 将同一浏览器、同源、同账号的状态修改串行化；每轮提示的发送标记在发出通知前保存，防止多个标签页重复发出系统通知。确认 / 稍后 / 跳过携带计时轮次，旧标签页的按钮不会重复计数或误处理新一轮提醒。设置有独立版本，编辑冲突时要求载入最新设置，不静默覆盖。

在不支持 Web Locks 的环境中（例如部分局域网普通 HTTP 页面），降级为前台窗口内提示并禁用系统通知，建议只开一个标签页；不承诺该环境下的跨窗口原子性。

**不是系统级闹钟。关闭网页、停止浏览器或电脑休眠时不保证提醒。** 不检测实际坐姿，不测量饮水量、运动时长或健康状态；默认间隔仅为可调整示例，不是健康建议。

## 数据与隐私

- 不新增后端接口、依赖或数据库字段；不访问外部服务，不发送本模块记录到服务器。
- 设置、暂停状态、时间戳和最近 7 个本地自然日（含今天）的手动确认记录保存在 `localStorage`，键为 `daynest.gentle-reminders.v1.<账号 ID>`，最多 5000 条。界面显示今日次数与今日最近 30 条；过期历史在下一次调度 / 确认时清理。
- 刷新会按原截止时间恢复；关闭页面不会偷偷替你暂停。退出登录或切换账号时写入停止标记，保留当时剩余时间；再次登录需要手动继续。关闭页面期间不生成虚假完成记录。
- 存储按账号分区，退出 / 切换会关闭当前通知、清空私有界面并使排队的旧账号操作失效。存储并未加密，同一个浏览器配置下的本机用户仍可读取；不应当作敏感健康档案。
- 不跨浏览器 / 设备 / 协议 / 端口同步，也不包含在服务器 JSON 快照或个人导出中。清除网站数据会丢失本机提醒记录。
- 损坏数据不会自动覆盖；无法保存时明确报错。底部「清除此账号的本机提醒数据」会在确认后停止并重置本模块，**无法撤销**，不影响服务器数据或其他账号的提醒数据。

新增测试覆盖资源接入与 Go 嵌入资源 HTTP 返回、默认不开启、不申请权限、设置边界、暂停续计、刷新恢复、专注 / 暂停 / 休息 / 过期阶段、跨午夜、免打扰、稍后 / 跳过、今日记录、过期清理、长时间休眠、多窗口串行去重、设置版本冲突、退出 / 切换隔离与旧请求失效、损坏数据保护 / 定向清除、无锁降级。浏览器模拟测试不发出真实通知，不读写实际个人记录。

动效测试另覆盖动画取消 / 快速重开、重复关闭、退出内容 inert 状态、设置展开反向操作、动态切换减少动态效果、后台收束、无动画 API 降级；控制器测试覆盖 Esc 焦点返回、常用间隔选中态、加减边界、禁用未填完整字段后的正常保存、两项提醒中的另一项 DOM 保持不变。模拟测试不能验证真实渲染帧率或视觉观感。

人工验收建议：桌面和手机宽度各检查一次浅 / 深色模式；设置 5 分钟并等待触发，检查专注期间延后及暂停 / 休息后出现；打开两个标签页同时确认同一轮，核对只增加一次；自己决定是否允许通知，再切换到其他标签页检查 OS 实际行为；退出登录再进入，核对必须手动继续。自动测试不能替代浏览器 / OS 权限与视觉验收。
