# 旅行手账（页面已下线）

旅行手账已从平台移除，不再展示导航入口、功能页、编辑弹窗或加载专属前端资源。快捷命令从现有导航生成，因此也不再包含旅行手账；旧代码触发旅行页面跳转时会回到“今天”。

## 历史数据保留

本次只下线前端功能，没有清空或迁移用户数据：

- JSON 快照中的 `travel_plans` 仍可读写，已有行程不会因后续保存快照而丢失。
- 个人数据导出仍包含当前账号的旅行记录。
- 原有旅行接口及其账号隔离、版本校验保留，用于兼容历史数据；不代表页面仍可用。
- 没有修改 `data/studyflow.json` 或其备份，也没有新增配置。

如需恢复原页面，可从 Git 历史恢复相应前端文件与入口。

## 验证与生效

重启 Go 服务并刷新浏览器，更新内嵌静态资源。

- `node tools/travel_ui_smoke.cjs`：确认页面、弹窗、样式、脚本和导航均移除，旧跳转回到首页，快照和导出字段保留。
- `node tools/daynest_ui_smoke.cjs`、`node tools/commands_ui_smoke.cjs`：导航和快捷命令回归。
- `go test ./...`：现有后端功能及历史旅行数据逻辑回归。
