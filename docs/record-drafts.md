# 心情长文与每周复盘：本机草稿恢复

交付日期：2026-11-02。对应 D-06 第二批，覆盖心情日记与每周复盘；[备忘录草稿](memo-drafts.md) 保持可用。正式服务仍使用周期 JSON 快照，SQLite 原型未接入实际数据。

## 在哪里使用

重启 Go 服务并刷新网页：

- **心情日记**：编辑卡片顶部的「本机草稿」。包含日记正文、表情、压力、精力、活动、关键词及原日期。
- **学习洞察 → 每周复盘**：卡片顶部的「本机草稿」。包含满意度、做得好的事、困难、经验、下周事项及原周次。

两个入口使用同一个弹窗，可切换类型，对照服务端后恢复。桌面并列展示，手机纵向阅读，支持深色主题。读取日记失败时提供「重新读取」，未载入记录前禁止填写 / 提交，避免把未知记录当作空白覆盖。

## 主要流程

1. 编辑时同步保留本机草稿，不自动提交心情或复盘。仅在当前账号登录已验证、原日期 / 周次已载入时捕获。
2. 切换日期 / 周次时，若最新文字已成功保留，提示「暂存并切换」；保留失败或已关闭时明确告知。切回原日期并不会自动恢复或提交历史草稿，须从草稿箱选择。
3. 刷新后打开草稿箱，查看本机与服务端的完整字段。点击「恢复到原编辑区」会回到原日期 / 周次，仍须手动保存。
4. 服务端已有其他修改时，禁止直接恢复到原记录。可以导出完整文字或显式「另存备忘录」，原记录与草稿均保留。另存成功后请核对备忘录，再按需删除草稿；请求超时而结果未确认时，应先核对列表，避免重复新建。
5. 保存过程中继续输入时，已提交部分与最新编辑分别处理；最新文字继续保留，下一次保存使用本次成功响应的版本。统计刷新失败不误报写入失败。
6. 已接收的响应丢失时不清理草稿。核对发现服务端内容一致后仍可恢复，手动保存确认；不会自动重放旧请求或省略版本条件。

原心情记录已删除时，旧草稿只能导出或另存备忘录，不自动重建原记录。每周复盘原有「最近 12 周」限制不变，超出可读取范围的旧草稿仍可查看、导出或另存。草稿不会自动过期。

「还原 / 放弃编辑区修改」仅还原已读取的服务端内容，已保留的本机草稿仍在。删除单份 / 清理全部草稿是单独操作，不删除服务端记录。继续编辑或切入后台时可重新产生草稿；若不希望保留，可关闭保留开关。

## 隔离、容量与隐私

- 使用已验证账号 ID 与服务地址隔离，沿用前端来源自身的 localStorage 隔离。令牌更新后同账号仍能找到原草稿，不把访问令牌写入草稿键或正文；服务地址 / 端口变化视作另一份空间。
- 退出账号后，本机草稿继续保留。编辑区、动态活动标签及恢复预览立即清空；登录其他账号不会列出旧草稿。重新登录原账号 / 服务后可以继续。
- 三个模块共用 `draft-store.js` 的不可变版本键：先写新一代，再清理旧一代；每个页面独立生成 ID。清理恢复来源时，不会误删另一窗口刚生成的新版本。既有备忘录键名与记录格式兼容，无须迁移。
- **备忘录、心情、复盘合计**，容量检查以所有账号 / 服务共 40 份、键和值 UTF-16 字节估算 4 MiB 为阈值。多个窗口同时生成草稿可能短暂超出估算阈值，最终以浏览器实际可用空间为准。配额、权限、损坏均提示，不自动淘汰旧文字；原文导出失败时仍保留草稿。
- 心情 / 复盘共用一个保留开关，与备忘录开关独立。关闭不自动删除既有草稿。长文草稿的清理按钮只作用于当前账号 / 服务的心情和复盘，不删除备忘录草稿或其他账号的数据。
- 草稿为**明文**，同系统用户可以通过浏览器工具访问。共用设备请先导出并清理。浏览器清理、无痕会话结束、App 卸载或系统清理均可能删除它，不可替代备份。

登录后断网仍可查看、导出已保留内容；尚不能在完全断网时重新登录并加载整个应用，也不跨设备同步本机草稿。安卓导出复用原生文件保存通道，但本轮浏览器演练只模拟该交接，未做 APK 或真机系统终止恢复验收。

## 保存契约与兼容行为

`PUT /api/v1/moods/{date}` 和 `PUT /api/v1/reviews/weekly/reflection` 新增可选字符串 `expected_version`：

| 值 | 语义 |
| --- | --- |
| 省略或 JSON null | 保留旧客户端无条件写入行为。 |
| 空字符串 | 仅在该账号此日期 / 周次尚无记录时创建。 |
| 最近读取的 `id + "@" + updated_at` | 原子比较后更新，保留 `updated_at` 完整精度。 |

版本包含记录 ID，防止删除后重建、时钟数值恰好相同时误接收旧编辑。Memory 在同一锁内核对并写入；仓储不支持原子能力时返回 409，不以读取再写入伪装原子操作。条件错误返回 400，过期 / 并发创建返回 409，均不更新记录。

`DELETE /api/v1/moods/{date}` 也支持可选查询参数 `expected_version`，新版心情页删除时携带已读版本。记录有变化时拒绝删除，保留页面与草稿。其他未升级调用方省略条件的行为仍兼容，不能据此宣称全平台都已具备并发保护。

编辑所依据的版本只随明确载入或本窗口成功保存而更新。后台刷新可以更新统计及记录列表，不能借此给未读的新版本授权，让旧编辑悄悄覆盖服务端。

同时修正长文长度：心情正文最多 6000 个 Unicode 字符、心情单个标签 / 活动最多 48 个字符；复盘每个长文栏 4000 个字符、每个下周事项 200 个字符。后端使用 rune 计数，不再把一个中文字算成三个字节。浏览器 `maxlength` 的 UTF-16 限制可能对 emoji 更严格。

「已提交服务」代表服务已接收，仍不等于立即写盘。周期快照、备份恢复与 SQLite 生产迁移门槛保持原状。
