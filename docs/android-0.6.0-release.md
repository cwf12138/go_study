# Android 0.6.0

应用 ID 为 `app.daynest.personal`，版本号为 `0.6.0`，versionCode 为 `6`。

- 登录、注册和连接设置面向小屏重新排版，连接恢复后可继续使用既有会话。
- 底部导航直达心情日历。备忘录可从「全部 → 记录」或「今天 → 随手记」进入。
- 智能规划按选定日期建立时间块，保存过程中保留继续编辑的内容，避免重复提交。
- 智能日历可安排未来 7 天的 Android 系统通知。展开通知可点「稍后 5 分钟」，改期、删除和退出后重新同步提醒。

先前的同一提醒实现已在荣耀 Android 15 通过息屏投递、模拟开机恢复和五分钟延后投递验收。真实重启后的系统广播送达仍待单独验证。[提醒验收记录](roadmap.md)

App 更新使用相同签名覆盖安装，保留本机数据。出包与安装方法见 [Android 构建说明](../mobile/README.md)。
