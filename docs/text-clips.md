# 文字快传

在「文件快传」顶部点击 **打开文字快传**，或按 `Ctrl/⌘ + K` 搜索“文字快传”。它适合在电脑和手机之间中转一段文字、收件地址、链接，或置顶保存经常需要复制的片段。与备忘录不同，不需要文件夹、排版或多步编辑；写完发送，另一台设备登录同一账号后同步即可复制。

## 使用

1. 填写文字，标题可留空；未填时用首行文字作为列表标题。
2. 选择有效期：1 小时、1 天、7 天或一直保留，默认 1 天。点击发送后按服务器时间起算。
3. 在另一台设备登录同一账号，进入相同入口点同步，或等待展开页面约 20 秒的自动刷新。当前只在已展开、页面可见时轮询，不自动读取系统剪贴板。
4. 点击文字卡片的“复制文字”。可以编辑、置顶、搜索标题及正文，按更新时间或发送时间排序，每页 6 条；置顶项在各视图优先显示。

“从剪贴板粘贴”只在点击时申请读取。浏览器拒绝或普通 HTTP 不支持时，可在文本框直接粘贴。自动复制不可用时会弹出已选中文字的窗口：电脑用 Ctrl/⌘ + C，手机长按复制。安卓工程接入了原生纯文字剪贴板，不读取剪贴板中的文件 URI，也不在后台监控。

## 有效期与清理

- 编辑正文、标题或置顶**不延长有效期**；改变有效期选项才重新计时。已过期项在对应视图可“续期 1 天”。置顶也会照常过期，常用片段可明确选择一直保留。
- “已过期”与“回收站”各自独立。移入回收站后可“恢复并保留 1 天”，包括原先一直保留的文字；按钮会明确显示恢复后的期限。
- 过期不会自动删除，不能从活动列表复制；仍可在过期视图编辑或续期。永久清理只允许对过期或回收站文字操作，确认后无法从应用恢复；释放条目配额。
- 每账号最多 100 条，含过期与回收站；每条最多 12000 个 Unicode 字符，标题最多 80 字。不执行粘贴的 HTML，不自动打开或请求其中的链接。

## 同步与草稿

文字由现有 Go 服务按账号保存，纳入 JSON 快照与个人数据导出（包括已过期和回收站内容）。两台设备需能访问同一服务。它不是公共剪贴板，不生成共享口令，不连接系统云剪贴板，也不提供离线写入。

网络失败会保留原请求和草稿，可原样重试，避免重复发送。其他设备修改了同一条记录时返回版本冲突，不自动覆盖；点击“核对服务器”查看对方版本，“基于此版本继续编辑我的草稿”保留自己的输入，手动合并后再保存。尚未确认的清理若已在服务器完成，核对或重试会按已清理处理。

切换账号、退出账号会清空页面中的旧账号文字和草稿；正常退出前沿用平台的未保存内容检查。草稿只在当前页面内存中，刷新或关闭前请保存或复制。同步不会覆盖正在编辑的输入，选择其他片段 / 新建时会确认放弃未保存修改。收起面板仍保留草稿。

记录和备份没有加密。不要把密码、验证码等秘密放在这里；HTTP 传输亦不加密。过期和永久清理不追溯擦除已有备份、个人导出或系统剪贴板；复制属于你的显式操作，退出账号不自动清除操作系统剪贴板。成功响应沿用项目内存状态与周期性落盘语义，不承诺每次操作都已立即写入磁盘。

## 更新与验证

重启 Go 服务并刷新网页。安卓端运行 `mobile/` 的 `android:sync` 并重新构建 APK，原生剪贴板也随新版工程更新；当前本机 SDK 不足，不能把 Java 测试桩编译当成 APK 构建或真机验证。

自动化覆盖入口按需加载、纯文字安全渲染、响应丢失重试、冲突核对合并、回收站恢复、手动复制、账号切换与过期筛选：

```powershell
go test ./...
go vet ./...
node tools/text_clips_smoke.cjs
```

API：`GET /api/v1/text-clips`、`PUT /api/v1/text-clips/{id}`、`DELETE /api/v1/text-clips/{id}?revision=...`，均需要 Bearer 登录。旧 JSON 快照无须手动增添字段，加载时自动初始化空集合；本次开发不直接修改用户数据。
