# 日历与备忘录视觉升级

本轮只调整页面展示及日历视图样式标记，不修改存储、日程接口、备忘录自动保存或个人数据。

新增 `internal/httpapi/assets/organizer-studio.css`，放在现有样式之后加载。所有规则限定在日历与备忘录页面内。

- 日历：暖色纸张、陶土色日期、清晰的日程层级、侧栏重排、周 / 日时间轴独立滚动；手机日视图取消整周的最小宽度。
- 备忘录：灰绿选中态、笔记颜色侧边标记、独立滚动区域、统一工具栏与正文间距、清晰的属性和保存状态。保留平板文件夹抽屉、手机列表 / 编辑切换以及专心写作模式。
- 两页均提供夜间主题、可见焦点与减少动态效果适配。未引入图片、外部字体或新增前端依赖。

检查命令：

```powershell
node tools/organizer_ui_smoke.cjs
node tools/calendar_ui_smoke.cjs
node tools/memos_ui_smoke.cjs
go test ./...
```

自动化检查不等于视觉验收。实际浏览器需检查 1440 / 1024 / 768 / 360 像素宽度、深浅主题、四种日历视图、备忘录长正文 / 空态 / 颜色标记，以及文件夹抽屉与专心写作模式。

源码运行通常刷新即可；复制静态目录或镜像部署需同步新增样式文件。
