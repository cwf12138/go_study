# Android 0.3.0 移动端适配

日期：2026-11-11。版本 0.3.0，versionCode 3，应用 ID `app.daynest.personal`。本轮以现有云端服务为前提完善客户端，不更换业务数据或存储方式。

## 修改内容

| 问题 | 调整 |
| --- | --- |
| 功能入口依赖侧栏，扩展入口不易发现 | 底部常用入口及可搜索的全部功能，保留全部 24 个页面 |
| 每个页面重复显示天气等信息、占用操作空间 | 信息集中今天页，其他页面使用紧凑标题栏 |
| 备忘录编辑区位于长页面下方，保存和其他操作分散 | 编辑区独立铺满可用高度，保存固定在编辑标题栏，更多操作集中收纳 |
| 键盘遮挡编辑区和弹窗，返回键直接离开记录页 | 依据可视高度调整，键盘弹出收起底栏；返回先关闭弹窗、再回列表 |
| 收藏页筛选及窄屏专注刻度横向超宽 | 限定可滚动区域，修正容器最小宽度及计时盘裁切 |
| 文件快传入口太深、分享地址仍是电脑局域网模式 | 直接传文件 / 发文字，复制当前选择的服务器地址 |
| 上传提示仍显示桌面 32 MiB | 手机提示与实际 8 MiB 限制一致 |
| 天气定位缺少 Android 权限声明 | 声明前台粗略 / 精确定位，由主动定位操作触发系统授权 |

新增 `mobile/src/mobile-ux.js`，仅装载于原生客户端。业务操作继续调用现有控件，沿用其账号、版本冲突、草稿和保存保护。未对网页端套用手机导航。
