# 心情日记界面升级

界面采用雾紫、暖白和鼠尾草绿的手账配色。大屏将日历/每日记录放在第一行、趋势/月度回顾放在第二行，同一行共享高度；窄屏按日历、记录、趋势、回顾依次排列。支持夜间主题与减少动画偏好。

- 日期格按心情类别着色；文字/表情同时表达含义，不只依赖颜色。底部圆点表示该日有日记。
- 提供“回到今天”、字数统计、保存状态，以及表情单选的方向键操作。
- 记录草稿不会被自动刷新覆盖，切换日期/月份及离页前提醒。保存期间的新修改保留为未保存内容。
- 删除需确认，删除进行中暂时禁用日记表单；成功写入与统计刷新失败分别提示。
- 趋势按日期升序展示，只连接相邻且都有记录的日期，不为缺失日期推测心情。图表提供可访问文本说明。
- “最长连续记录”明确对应后端最长连续记录统计，不再暗示它是截至今天的连续天数。

草稿仅存在当前页面内存，仍需手动点击保存；不支持离线持久化。没有改变数据格式或用户数据。

验证：`node tools/mood_ui_smoke.cjs`、`go test ./...`。测试使用模拟 DOM 和网络；本次工具环境无可连接浏览器，未完成实际视觉验收。
