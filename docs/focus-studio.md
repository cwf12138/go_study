# 专注空间

本次调整仅涉及前端，不修改 API、存储结构或历史专注记录。新增样式独立放在 `internal/httpapi/assets/focus-studio.css`，限定在 `#panel-focus` 内。

## 布局与交互

- 桌面使用共用网格行，让「时钟 / 设置」和「任务 / 每日积累」分别对齐；窄屏顺序展示，保留全部操作。
- 浅色采用纸白、灰绿；夜间采用深色表面。运行、暂停、休息用不同配色和文字区分，不只依赖颜色。
- 表盘内只显示居中的阶段倒计时，不重复显示暂停和剩余说明。数字使用等宽数字，避免每秒跳动。
- 支持 15 / 25 / 45 / 60 分钟预设及 1–240 分钟自定义。分段流程中显示每段计划时长，并突出当前阶段；例如 25 分钟加休息为 12:30 → 5:00 → 12:30。
- 开始请求期间禁用设置和重复提交；恢复会话后，设置区域显示服务端真实参数。选中的任务即使不在前五项中，也会显示在预览列表顶部。
- 简洁模式仅在有会话时可用，只收起辅助卡片，不使用浏览器全屏，不隐藏全局天气和导航。Esc、退出按钮、切换页面或结束会话均可恢复布局。
- 放弃前二次确认；如需保留已投入的时间，应选择「完成并记录」。每日统计只包含已完成记录，不包括休息、暂停或已放弃会话。
- 到时推进 / 结算失败会保留错误说明及重试按钮。重试先读取当前会话：如果服务端已推进或结束，直接同步；否则重发对应操作，避免丢失响应后重复推进。
- 控件支持键盘焦点、预设选中状态与阶段语义；倒计时不会每秒触发屏幕阅读器播报。系统开启减少动态效果时停用过渡动画。

## 自动检查

从仓库根目录运行：

```powershell
node --check internal/httpapi/assets/app.js
node tools/focus_ui_smoke.cjs
node tools/app_sync_smoke.cjs
go test ./...
```

Focus 测试在模拟 DOM、时钟和网络中执行实际控制器，覆盖表单绑定、奇数分钟分段、暂停 / 继续、恢复参数、重复提交、任务安全转义、简洁模式和失败重试。不使用真实账号或修改数据快照；这不替代浏览器视觉测试。

## 浏览器验收清单

当前自动化环境没有可连接的浏览器，以下项目仍需真实浏览器验收：

1. 刷新页面，在 1440、1024、768 和 360 像素宽度分别检查布局；无横向溢出，所有按钮可见。切换夜间主题检查表盘、表单、统计和焦点对比度。
2. 选择 25 分钟并启用休息，确认预览为两段 12 分 30 秒与 5 分钟休息；修改成自定义值后，预设高亮正确更新。
3. 使用测试任务开启 1 分钟带休息的会话。暂停后等待数秒再继续，计时不因暂停减少；刷新后恢复当前阶段和设置。
4. 在运行 / 暂停时进入简洁模式，分别通过 Esc、退出按钮和切换页面退出；确认计时和任务关联不受影响。
5. 在测试会话阶段即将到时前，用开发者工具切为离线。到时显示失败说明；恢复网络后点重试，进入正确阶段。只应核对状态 / 推进一次，不应跳过中间休息。
6. 在测试账号里确认完成后更新累计，放弃时先提示确认，取消确认不会结束计时。检查长任务名和选中第六项之后的任务。

资源由 Go 直接托管：本地源码运行通常刷新页面即可看到此次更新。若部署时复制静态目录或使用 Docker 镜像，需要同步完整资源目录 / 重建镜像。
