# D-09 · 从一条记录到一次行动

本轮将已有四个页面串联起来，不增加独立功能页。更新后需要重启 Go 服务并刷新页面；安卓客户端还需要重新构建安装包才能获得新资源。

## 使用方式

1. 在备忘录正文选中同一行里的文字，点击编辑工具栏的「↗ 关联待办」。系统使用这一整行作为来源；未选中文字时使用备忘录标题。
2. 确认待办名称、优先级、截止日期和是否加入今天，创建到收集箱。保存有冲突或尚未确认时，需要先处理原备忘录的保存问题。
3. 在关联详情点击「为它安排专注」，选择时长与休息设置后手动开始。待办卡片也可以通过「来源与专注 / 专注记录」进入。
4. 专注可暂停、继续和结束。结束专注只记录投入时间；待办需要明确勾选完成，备忘录中的复选框独立保留。
5. 智能日历展示已完成专注，并提供待办与来源回查。无截止时间但加入「我的一天」的待办，也会出现在相应日期。有截止时间时优先按截止日期展示。

详情展示当前待办状态、创建时的引用、来源是否修改 / 删除、已完成专注总分钟数及最近 20 次会话。日历按会话开始日期归档，采用现有日历的上海时区；放弃的会话只留在关联历史，不计入完成积累。旧会话没有标题快照时使用已有信息回退。

## 重复操作和删除

- 同一账号、同一备忘录、同一种来源以及同一段规范化文字，只关联一个待办；列表前缀、空白和 Markdown 勾选状态不改变身份。两行相同文字也视为同一来源。需要另一项相似工作时，可单独创建普通待办。
- 重复提交返回原来的关联，不把新填写的名称或日期悄悄覆盖到旧待办。首次创建会核对备忘录版本、所有权和来源文字。
- 关联回执、待办及首次需要的收集箱在 Memory 的同一锁内创建。删除待办不会移除回执；原关联不能用来复活已删除的待办。
- **引用是一份独立副本**：关联会保存备忘录标题和这一行引用，删除原文或待办后仍保留历史。它们包括在个人 JSON、账号统计和完整服务备份中。不要将删除原文理解为删除所有关联副本。
- 新的待办专注必须携带稳定的 `request_id`。同一次请求重试返回原会话，包括已结束的会话；同一 ID 改写参数会冲突。目标检查和单一活动会话检查在同一锁中完成。
- 待办专注的暂停、继续、阶段推进和结束使用条件更新，迟到的暂停 / 继续不会覆盖已经结束的状态。相同结果的结束请求可重复确认。

这些是内存原子操作，**不代表响应时已经落盘**。服务仍使用默认每 15 秒尝试的 JSON 快照；异常退出可能丢失最近修改。快照包含新关联集合，旧快照可直接读取。没有切换正式 SQLite，也没有承诺离线同步。

## 请求结果不明

发出新关联或待办专注前，客户端按已核验的账号和服务地址保存原始参数，不保存令牌。保存不了本机记录时，不发送新操作。每种操作最多保留一项，不静默覆盖。

网络中断后，右下角会出现「有操作待确认」：

- 「核对结果」只读取服务端回执或原始会话。
- 「原样重试」使用原参数及原请求 ID，不生成新操作，也不会自动重发。
- 「移除本机追踪」需明确确认，只清除本机追踪，不会撤销服务端操作。

有未核对的待办专注时，先核对再开启另一段专注。异常成功响应不会清除待核对记录。切换账号 / 服务后的迟到响应不会写进新界面。操作记录包含所选文字与待办名称，应按个人设备上的本机数据管理。

## 新接口

| 接口 | 用途 |
| --- | --- |
| `POST /api/v1/memos/{note_id}/actions` | 按来源幂等创建待办和关联；首次 201，重放 200。 |
| `GET /api/v1/memos/{note_id}/actions` | 当前账号对这篇备忘录的历史关联；原文删除后已有回执仍可查。 |
| `GET /api/v1/action-links/{action_id}` | 关联、来源摘要、可空的待办与专注历史。 |
| `GET /api/v1/todos/{todo_id}/context` | 普通待办或关联待办的详情；已删的普通待办返回 404。 |
| `POST /api/v1/focus-sessions` | 新增互斥的 `todo_id` 和必填 `request_id` 分支；既有学习任务 / 时间块分支保留。 |
| `GET /api/v1/focus-sessions/requests/{request_id}` | 按当前账号核对原会话。 |
| `GET /api/v1/calendar` | 新增只读的 `focus_sessions` 投影，不另存一份日程。 |

所有接口使用现有身份验证和账号隔离。新原子能力通过窄接口调用 Memory；不具备能力的仓储拒绝新流程。SQLite 隔离原型尚未实现这组正式能力，不能接管生产服务。

## 验证记录

- Go：并发创建只有一份待办 / 收集箱 / 回执，旧版本与不存在的来源不产生副作用；跨账号拒绝，删除与快照重载后仍不重复创建，导出和统计包含关联。
- 专注：请求 ID 重试 / 改参冲突、暂停与休息不计入专注、迟到继续不能复活会话、结束重试、显式完成边界，以及无截止待办和专注的日历投影。
- `tools/actions_smoke.cjs`：行选区与规范化、账号 / 服务隔离、存储损坏和配额失败。
- `tools/actions_browser.cjs`：真实 Go 服务和 Edge，使用独立临时数据验证完整链路、明确勾选、删除、两种响应丢失后的核对、换账号以及桌面 / 手机尺寸 / 深色截图。

浏览器报告在 `.local/checks/actions-browser-report.json`，不含实际用户正文。浏览器演练不是安卓真机验收。
