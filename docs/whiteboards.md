## 打开就可以写画

新建时只填白板名称，可选空白、一天的安排或想法发散模板；模板中的对象都能修改。打开编辑器后，选择工具再在画布上点击或拖动：

- **便签 / 文字**：点击放置，随后在弹窗编写文字；双击对象或点「编辑文字」再次修改。支持 18/24/32/40 四档字号。文字按对象宽度折行，超出边界会裁切，但完整内容仍保存。
- **画笔**：鼠标、触摸或手写笔拖动；没有压感、橡皮擦、吸附或笔迹识别。笔画是可选中的独立对象，删除对象相当于删除整条笔迹。
- **矩形 / 圆形 / 箭头**：按下并拖动绘制。圆形可拉为椭圆；箭头是独立线段，不会自动绑定图形，图形移动后箭头需手动调整。
- **选择**：单击选中，拖动移动；矩形、圆形、文字和便签右下角有大小手柄。下方对象列表也可选择对象，随后编辑文字、更改颜色、复制、置前或删除。
- **平移与缩放**：选平移工具，或按住空格拖动；用 +/- 或 Ctrl/⌘+滚轮缩放，支持 50%–400%，「适应画布」还原。画布固定 1600×1000，不是无限画布；视口外的内容可以通过适应画布找回。
- **撤销 / 重做**：保留当前打开白板最近 25 次修改，Ctrl/⌘+Z / Ctrl/⌘+Shift+Z。关闭编辑器、换白板或刷新后历史清空。删除对象可在当前历史中撤销。

键盘工具 V 选择、H 平移、P 画笔、N 便签、T 文字、R 矩形、O 圆形、A 箭头；Delete/Backspace 删除选中对象。编辑文字、名称或弹窗输入时不会触发绘图快捷键。支持 Ctrl/⌘+S 保存，只有当前白板页激活时拦截快捷键。键盘不能代替拖动绘图，非视觉绘图体验仍有限。

## 保存与安全

- **手动保存**至本机 Go 服务，随后纳入原有定时 JSON 快照及个人 JSON 数据导出。刚新建的白板只是内存草稿，点保存才会出现在白板列表中。
- 未保存时切换白板或关闭编辑器需要确认；切换应用内其他功能页会保留编辑器状态，返回可以继续。刷新/关闭标签页会请求浏览器提醒（是否显示由浏览器决定）；退出或切换账号清空草稿，请先保存。
- 断网/超时/未知结果保留草稿和不可变原请求，可「原样重试保存」。版本冲突不会覆盖其他窗口的数据；可先导出 SVG，再「放弃草稿并重载」。如果上次保存已经成功，重载会读到该版本，并不撤销保存。
- 「导出 SVG」导出当前画面（含未保存草稿），不含选择框；矢量图包含文本和笔迹，不引用外部图片、字体或脚本。没有 SVG 导入，导出图不能用本功能重新载入为可编辑白板；继续编辑请保存到账号。SVG 不包含撤销历史或标题。
- 我的白板 / 回收站、名称搜索、每页 6 张、缩略图预览。缩略图只简略绘制前 40 个对象，不显示文字；打开后是完整画面。移入回收站可恢复，没有永久删除按钮。
- 当前不是协同白板，不联网共享，也不接入 AI。不同账号隔离；JSON 快照本身不加密，注意保护备份。
- 每账号最多 60 张白板（含回收站），每张最多 250 个对象、30,000 个总路径采样点，每条笔迹最多 1,000 点，单个文字最多 1,000 字。颜色限定内置九色；形状与坐标在前后端校验。HTTP 请求仍受原有 1 MiB 正文限制。

## API

`GET /api/v1/whiteboards` 返回当前账号所有已保存白板（含回收站）。`PUT /api/v1/whiteboards/{id}` 整体保存 `title,nodes,deleted,revision`，创建用版本 0，更新用当前版本。ID 为 8–80 个字母、数字、下划线或连字符。服务端生成用户与时间字段；严格拒绝未知 JSON 字段。

相同原请求在紧接着的成功保存后重试返回原结果，不增加版本。已有其他修改时返回 409，不覆盖新版本。400 为输入校验失败，401 未登录，404 当前账号无对应记录。坐标范围 x=0–1600、y=0–1000；图形不能超出画布。存储深拷贝嵌套路径，版本检查与整体替换原子完成；旧快照没有 `whiteboards` 字段时视为空列表。
