# D-10 第二批 · 待办与当日安排离线查看

本批扩展已有离线资料库，提供「备忘录 / 待办 / 当日安排」三个入口。待办与安排使用独立开关，原有备忘录快照和草稿格式保持兼容。没有离线完成、删除、创建日程或自动重放写入。

## 使用方式

1. 在线登录，在「待办清单」点击「离线资料」，或点击「智能日历」工具栏的资料图标。
2. 开启「保留待办与当日安排」。系统读取完整待办、分类及所选日期的完整安排，全部成功并通过检查后才保留。
3. 可选择另一个日期，点击「更新此日与待办」。从智能日历打开时会带入当前选定日期。
4. 点击「打开待办与安排」进入对应标签。之后可以从登录页或安卓连接页再次打开资料库。

默认关闭。备忘录和规划快照各自开启、清空，互不连带；退出或当前会话被确认过期时，清除当前账号的两种快照。本机草稿和服务端原文不受快照清理影响。

## 能查看什么

| 内容 | 能力与范围 |
| --- | --- |
| 待办 | 完整清单、已完成状态、备注、步骤、标签、截止时间、我的一天、分类和优先级。支持组合筛选、搜索及展开步骤；状态标记是只读文本。 |
| 当日安排 | 最多 7 个确实读取过的日期；个人日程、计划时段、学习任务、待办、已完成专注、心情标记、运动摘要和生活保养。支持日期 / 来源筛选及搜索。 |
| 时间 | 明确标注北京时间、保留时间及原文时间；非今天的安排提示「不是今天」，旧待办提示尚未核对今天的变化。跨午夜日程按真实重叠时间展示。 |
| 导出 | 导出当前筛选为 Markdown，标明它是快照和筛选结果。安卓复用原生文件通道，电脑不可达时也可导出。 |

心情只保留标记，不复制日记正文；运动只保留日历摘要，不复制完整训练明细。安排副本保留必要的标题、说明、地点与状态，没有在线操作按钮或外部资源加载。

「没有某天快照」与「该天保留时没有安排」分开显示，不能把网络失败当成空数据。日期下拉框只列出已保留日期。

## 完整性与容量

- 完整待办最多 500 项；最近保留的日期最多 7 个，每天最多 300 项安排；规划快照共用 512 KiB。超过任一限制会提示未更新，不截断后冒充完整清单。
- 日期支持 2000–2099 年；日历日界线和展示使用 `Asia/Shanghai`。列表按真实时间排序，支持接口返回不同 UTC 偏移的时间。
- 待办列表、分类和日安排通过现有读取接口获取，校验账号、范围、必需字段、重复 ID 和容量，组合成功后一次替换本机记录。它不是服务端事务快照；其他设备仍可能在读取期间修改数据。
- 普通读取失败、超时、格式异常或存储空间不足，保留此前副本；格式损坏时提供明确清理入口，不自动覆盖。
- 页面可见且保留已开启时，约每分钟、返回窗口或恢复联网时尝试更新今天。自动读取不会打断正在进行的手动日期更新；没有启用时不增加这批请求。

## 在线修改与迟到响应

本批为主应用、日历、共用 HTTP 客户端、运动及生活保养的相关写入接入快照失效观察：

1. 发出相关在线写入前，取消规划快照读取并作废旧规划副本，防止继续展示已知可能改变的状态。
2. 写入结束后再次作废，防止写入过程中其他窗口读取的旧状态回填。
3. 相关操作结束且当前账号仍匹配时，再尝试读取新副本。成功后恢复完整快照；失败时显示等待更新，不把旧任务继续显示为未完成。
4. 每次读取核对账号、服务、会话、请求代次及本机快照标记。关闭开关、清空、切账号或其他窗口更新后，迟到结果不回填。

这些标记用于只读缓存的失效检查，不是离线同步协议或跨设备事务。未被本机观察到的远端修改，仍需重新读取才能获知，因此始终保留快照与时间提示。没有自动重试业务写入。

## 网页与安卓边界

- 网页沿用 `/offline/`，缓存只包含公开阅读界面。需要在浏览器支持的安全上下文准备后，才能断网刷新或重新打开；普通局域网 HTTP 的限制不变。
- Service Worker 升级到第二版资源清单，包含规划阅读脚本；等待安装完成后才显示已准备。业务接口和令牌不进入其 Cache Storage。
- 安卓使用安装包内置资源。电脑不可达时，可从连接页打开；待办和日安排仍不加载完整业务脚本、不请求业务接口。
- 两种快照复用原有账号 / 服务隔离及令牌摘要索引。读取、导出、清理前复核，换账号 / 电脑后清空旧内容和搜索词。
- 本机快照是可清理的普通本地存储，没有额外加密，也不是备份。服务端仍使用原有 JSON 周期快照，没有数据库迁移或写盘承诺变化。

更新后重启 Go 并刷新网页。安卓资源需重新构建安装包；本轮只同步工程资源并验证模拟原生桥，没有 APK 或真机验收。
