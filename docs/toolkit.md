# 随身工具

入口位于左侧“今天”分组，也能通过 `Ctrl/⌘ + K` 快捷导航打开。参考手机常见计算器、计时器和秒表的操作方式，集中在一个页面，不增加多个一级导航。

设计参考：[Apple 计算器使用说明](https://support.apple.com/zh-cn/guide/iphone/iph6a38eb783/ios)、[单位换算说明](https://support.apple.com/zh-tw/guide/iphone/iph69d274dde/ios)、[秒表与分段](https://support.apple.com/zh-cn/guide/iphone/iph96b1e460/27/ios/27)。并非这些系统应用的完整复刻。

## 七个工具

- **计算器**：加减乘除、括号、负数、小数、科学计数法、百分号，支持键盘 Enter、退格和 Esc 清空。严格解析算式，不使用 `eval`。最多 160 字符，保留最近 20 条成功计算，可点击重用、清空或复制结果。百分号固定代表除以 100，`100 + 10% = 100.1`，不是手机某些计算器的“加成 10%”语义。结果最多 14 位有效数字，采用浮点近似，不用于财务结算。
  - 顶部可切换“基础 / 科学”，不会清空当前算式。科学模式增加平方、幂、平方根、立方根、三角函数、常用/自然对数、指数、阶乘、倒数、绝对值与 π/e 常数。
  - DEG 表示角度，RAD 表示弧度；历史记录保留角度单位，点击历史时恢复。函数按键包裹选中内容；未选择时包裹整个算式，空输入时插入函数开头。
  - 幂右结合：`2^3^2 = 512`；幂先于一元负号：`-2^2 = -4`，负底数请加括号。阶乘支持 0–170 的整数；不提供复数计算。数字和常数、两个括号之间相乘需明确输入 `×`，如 `2×π`。
- **倒计时**：单个 1 秒至 24 小时计时器，名称、常用时长、暂停／继续／重置、可选提示音。运行或暂停时锁定时长设置；到时可再计一次。切换功能页后，内容区顶部仍能查看状态并返回计时器。完全独立于专注会话，不写入专注统计。
- **秒表**：开始、暂停、继续、分段和重置；最多 50 个分段，展示单段及累计用时。重置运行中的秒表或已有分段时要求确认。显示百分之一秒，但不是专业测量精度。
- **单位换算**：长度、重量、温度、面积、容量、时间。输入即换算，支持交换单位及复制结果。没有需要联网的汇率功能；时间中的“天”固定为 24 小时，不计算夏令时或自然月。结果最多 12 位有效数字，温度校验绝对零度。
- **时钟**：独立的“时钟”标签，指针表盘、数字时间、日期和星期同步更新。默认跟随设备本地时区，也可选择北京、东京、伦敦、纽约；支持 12/24 小时制、隐藏秒针/秒数、简洁表盘。时间来自设备，不进行联网校时；城市夏令时由浏览器 IANA 时区数据处理。秒针不使用旋转过渡，避免跨整分时倒转，也适合减少动画偏好。

- **图片瘦身**：选择一张本机 JPEG / PNG / WebP，设置最大边长、输出格式与质量，预览处理结果、大小变化并下载。不上传、不覆盖原图；支持最大 15 MB / 2400 万像素，不放大小图。JPEG 透明区域填白；PNG 不使用质量参数；动画仅处理一帧，不保留原文件元数据。输出可能更大，浏览器不支持格式时会说明回退，并按实际格式下载。
- **随身录音**：开始、暂停、继续、结束、试听、命名与下载。只有点击开始才申请麦克风；离开工具或切换浏览器标签页自动结束并释放麦克风。最多 30 分钟有效录制时间或约 50 MB；暂停不计时。仅保留最近一段，重录/清空前确认。支持取消等待权限，迟到的授权会释放设备而不开始录音。

录音交互参考 [Apple 语音备忘录](https://support.apple.com/zh-cn/guide/iphone/iph4d2a39a3b/ios)，但不提供原生应用的后台持续录音、剪辑和云同步。实现依赖 [MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder) 与 [getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)：需要 HTTPS 或 localhost、浏览器支持和麦克风授权；普通局域网 HTTP 不保证可用。文件格式由浏览器决定（如 WebM、M4A、Ogg），不保证 MP3。录制他人声音前请征得同意。图片处理使用 [canvas.toBlob](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/toBlob)。

## 本机记录与边界

计算器模式/角度单位、时钟偏好、计算历史、倒计时和秒表写入当前标签页的 `sessionStorage`，按账号 ID 分开。同标签页刷新可恢复；切换账号或退出登录会清理上一账号的工具记录。关闭标签页通常清空记录，浏览器的会话恢复或复制标签页可能保留副本，不能作为可靠的长期保存。多个标签页各自独立运行，不做跨页协同。单位输入、计算器未提交算式和简洁表盘展开状态不保存。

图片和录音只在内存中，不写入 sessionStorage。刷新、关闭或退出账号即清理，录音请及时下载。切换到其他工具会结束录音但保留当前录音供返回试听/下载；退出账号会直接清空。关闭前的未保存提醒受浏览器限制，不能作为保存保证。录音上限由网页事件检查，后台节流或设备休眠不能保证精确停止。

这些工具不请求外部数据，不上传结果，没有新增 Go API、数据库字段或环境变量，不包含在个人服务器数据导出中。页面资源本身仍由 Go 服务提供，**并非新增离线 PWA**。

计时按时间戳计算，而不是依赖每次回调减一。后台节流后再次执行、回到页面或刷新会根据目标时间恢复；手动修改系统时钟会影响计时结果。浏览器关闭、系统休眠、静音或自动播放限制可能导致无法准时响铃；只播放一次短提示音，不提供系统级闹钟、推送通知或后台唤醒。请勿用于药物、烹饪安全等必须准时提醒的事项。

## 验证

更新后重启 Go 服务并刷新页面。

- `node tools/toolkit_ui_smoke.cjs`：基础/科学算术、非法输入、六类单位、暂停继续、计时到期、刷新恢复、分段、标签页切换、账户清理与 DOM 引用；含模式切换、历史角度恢复、时钟跨日、12 小时制与纽约冬夏时差。
- `node tools/toolkit_pocket_smoke.cjs`：图片参数/格式回退/取消、录音权限失败/迟到授权/暂停继续/最终音频块/时长上限/页面切换/账号清理、临时 URL 回收。浏览器图片和麦克风 API 使用模拟，不访问真实设备或个人文件。
- `node tools/daynest_ui_smoke.cjs`、`node tools/commands_ui_smoke.cjs`、`node tools/layout_smoke.cjs`：导航、快捷入口与布局基础回归。
- `go test ./...`：静态资源嵌入及现有服务回归。

窄屏、夜间主题、键盘标签页导航和减少动画偏好已在样式与交互中实现；未完成真实浏览器截图、真实照片编码和麦克风/提示音试听验收，设备兼容性仍需实际浏览器验证。

## 顶部节假日倒计时

原日期计算工具已移除，改为全局顶部的节假日小组件，与天气、今日签同组显示。点击查看日期范围、当前假期和数据说明，支持手动刷新。窄屏下三个入口一起换到下一行，不拆散。

- 默认中国大陆的七类全国性节假日，不包含普通周末、地方或单位假期。后端以北京时间日期计算距离下一假期首日的自然日天数；当前已在假期中时，顶部展示下一假期，详情同时提示当前假期。
- 已核实的 2026 年数据来自[国务院办公厅放假通知（北京市政府转载）](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)。数据内置，运行时不依赖外部节假日服务。
- **未收录官方安排的年份只倒计时到节日当天**，农历节日及清明由现有 lunar-go 库换算，明确显示“调休待更新”，不提供猜测的假期长度。支持当前年份 1900–2099；超出范围显示暂无数据。
- 维护入口为 `internal/service/holidays.go` 的 `holidayYear`。每年须核对官方通知后补充新年度起止日期、时长、来源链接与 `ScheduleThrough`，并更新测试；当前不是联网自动同步调休。
- `GET /api/v1/holidays/next` 需要登录，仅计算公共日期，不读写个人数据。前端每分钟检查跨日、每 15 分钟更新；返回页面也检查。请求有超时、重试和账号切换时的过期响应隔离，不展示失败时编造的天数。
- 验证：`go test ./...`、`node tools/holiday_ui_smoke.cjs`，涵盖跨年、北京时间零点、春节放假首日、假期中/末日、补班日、未核实年份、失败重试和旧请求隔离。浏览器视觉效果仍需实际验收。
