# 数据中心

日期：2026-11-01。对应路线图 R1「数据中心」的第一批可用能力；不改变现有周期 JSON 存储，也没有接管或迁移实际数据。

## 使用入口

重启新版 Go 服务并刷新网页，点击右上角 **⚙ 设置与诊断 → 数据中心**。原「连接与诊断」保留快照写盘、连接和版本信息。数据中心不增加一级功能页面，电脑与手机共用入口；安卓需重新同步资源并构建安装包后才能使用新版界面。

概览仅在打开该标签或主动点击「重新读取」时请求，不后台轮询、不读取浏览器剪贴板，也不访问你保存的备份包。数据属于当前账号；关闭窗口会停止等待请求。换账号或切换服务地址会清除本页旧结果。

## 能看到什么

- **服务端记录对象**：当前内存仓储中属于你的记录，含文件夹、配置、回收站、过期项及保留历史内容。它不是任务完成数、真实内容去重数或已确认写盘数；旧知识笔记原件与已迁入的备忘录是两种保留对象，会分别统计。
- **记录分布**：备忘与安排、生活与物品、身心与习惯、学习与阅读、探索与回忆、保留历史内容。展开查看各集合数量，部分分组可直接回到原页面。旧知识笔记原件明确标记为仅完整服务备份保留，不承诺个人 JSON 覆盖所有底层快照集合。
- **快传配额**：按当前账号的附件元数据累计，含过期、回收站与缺失索引。它不是整个目录的物理空间，不统计缓存、孤立文件、安装包或其他账号。配额仍为 256 MiB / 100 个文件。
- **独立状态**：记录统计和附件信息分别显示是否可用；元数据错误或读取失败时不会显示一个假的零占用。断线时保留上次概览，并停用附件检查，重新读取成功后可继续。

统计不序列化笔记正文，不返回账号 ID、其他账号数量或本机路径，也不初始化规划默认配置。所有业务写入仍沿用现有保存规则；提交成功不等于立即落盘。

## 附件完整性检查

点击快捷入口「检查附件」，再点击「开始附件检查」。只检查当前账号**已有索引**的快传文件，包括过期及回收站项。内容读取使用流式 SHA-256，既核对大小，也能发现长度相同但内容被改动的文件。

| 结果 | 含义 |
| --- | --- |
| 本次内容一致 | 本次范围内的文件大小与其元数据哈希一致，不证明文件来源、备份存在或恢复成功。 |
| 文件缺失 | 对应 blob 文件不存在。 |
| 内容不符 | 大小或内容哈希与元数据不同。 |
| 无法读取 | 文件权限、特殊文件或其他读取问题导致无法确认。 |
| 需要重查 | 检查期间元数据 / 文件发生变化，或对应上传进行中，没有误报为通过。 |
| 暂无附件 | 没有可检查的索引，不等于整个数据目录为空。 |

异常列表只显示当前账号的文件名与状态，文件名按文本转义。它属于私人数据，不会加入脱敏诊断导出。结果只留在当前页面内存，不写入服务快照或浏览器存储。

每个服务内的快传 Store 同时最多一个检查；繁忙返回 429。单次范围上限为 100 个索引 / 256 MiB，超出时需要电脑端离线校验。哈希读取期间不持有元数据锁，上传与普通文件管理可以继续；发生变化的项需要稍后重查。请求取消后不返回半份“通过”结果；原生桥断开等待不一定立刻结束服务端读取，因此界面会明确说明。

本功能**不扫描孤立文件，不修改、修复、续期或删除文件，不创建备份，也不验证恢复**。使用公开开发 JWT 密钥时，局域网客户端不能读取附件详情或执行此检查，沿用文件快传的本机访问限制。

## 两种副本的区别

「导出个人 JSON」调用现有账号级导出接口，不包含密码、快传文件及元数据、浏览器草稿或手机本地设置。当前入口最多接收 64 MiB；网页端读取时即限制大小，安卓继续使用原生系统保存通道。超出时使用电脑端完整备份。浏览器下载或系统保存窗口已接手，不等于你已经完成异地备份；页面只记录本次会话的交付提示，重开应用不会伪造服务端“最近备份成功”。

「完整备份」在电脑端正常停服后执行，覆盖全部账号快照、滚动备份与快传文件。可以从此页下载不含个人数据的操作说明；本页不提供任意账号可下载的全服务备份接口，也没有覆盖实际目录的恢复按钮。具体命令和独立目录验收见 [完整备份与恢复](backup-restore.md)。

## 接口与验证

- `GET /api/v1/data-center`：账号概览，需要 Bearer 登录，不缓存。
- `POST /api/v1/data-center/transfers/check`：主动只读检查，无需请求体，需要登录及快传访问权限。

接口定义见 [OpenAPI](openapi.yaml)。服务端有账号隔离、私密字段不输出、部分失败、默认密钥边界、相同大小内容篡改、缺失 / 不可读附件、过期 / 回收站、忙碌 / 取消等测试；前端测试覆盖严格数据验证、文件名转义、历史状态、账号 / 服务切换、迟到请求、导出保护和键盘标签。

本批通过 Go 全量测试、静态检查和 57 项前端检查。另在真实 Edge 浏览器中，用临时 Go 服务与测试账号检查了桌面 / 390px / 深色布局、正常与篡改附件、取消等待、断线状态、键盘操作及保存通道交付；原生桥和文件保存接口为模拟，不代表 APK、系统保存权限或安卓真机验收。实际用户数据未读取或改动。

SQLite 已提供[独立验证原型](sqlite-prototype.md)，尚未接管正式存储；[本机草稿](record-drafts.md) 已覆盖三个记录流程，物理空间精确盘点和个人 JSON 导入仍待推进。当前页面不会把原型测试标成真实用户数据已迁移。

2026-11-03 起，概览与附件检查接入[共用请求客户端](http-client.md)，统一取消、异常响应与登录过期提示。文件导出仍走专用通道；取消等待不证明服务端检查已经停止，也不自动发起第二次检查。

## 本机收集与服务端回执

新的待办提交回执计入「本机待办提交回执」服务端记录，包含在个人 JSON 与完整服务备份中；目标删除后仍保留，用于原样重试的去重。设备 IndexedDB 中的未发送草稿、原文与确认副本属于本机数据，不在服务端统计 / 导出 / 备份内，需从本机收集显式导出或清理；清理只读资料不会清理它们。详见 [本机收集说明](offline-todo-outbox.md)。

2026-11-05：新增「日程新建回执」统计与个人 JSON 的 `calendar_commands`。回执随完整服务备份保留，目标已删除仍用于去重。浏览器本机提交原文 / 确认标记属于设备数据，不在服务端统计或备份中，需从日历的提交记录入口导出或清理。详见 [日程保存说明](calendar-editing.md)。
