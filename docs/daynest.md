# 日常 · Daynest 升级验收

## 安全升级

1. 保存旧页面未提交的草稿；停止 Go 服务（让退出持久化完成），单独复制 `data/studyflow.json` 留档。
2. 使用原配置运行 `go run ./cmd/api`。有待导入笔记时，日志显示 `knowledge notes copied into memos; originals retained` 及数量。没有旧笔记不会触发迁移写盘。
3. 刷新网页，登录原账号，在“记录 → 备忘录 → 知识花园（已迁入）”检查内容、标签、置顶和日期。
4. 再次启动不会重复导入。编辑或删除迁入笔记后再次启动，不应覆盖编辑或恢复删除。不要手动移除快照中的 `knowledge_memo_migrations` 回执。

原始知识记录保留用于恢复及旧 API 兼容，未被物理删除。新增的旧知识记录会在下次启动时导入，已导入记录不再跟踪旧接口修改。快照备份未加密，请妥善保管。

## 页面与交互

- 桌面端：检查四组导航可滚动，底部功能可达；18 个导航按钮均打开正确页面，品牌点击返回“今天”。
- 首页：今日安排取日历的一天区间（结束日不包含）；展示最多 5 条日程/规划。日历数据按现有服务的北京时间解释日期。
- 待办：展示“我的一天”、当日截止和逾期的未完成项，最多 5 条；点击圆圈完成，刷新后仍完成；更多内容在完整待办页查看。
- 日程/待办数据请求失败时应显示错误提示，不能误报为空；顶部刷新按钮可以重试。
- 随手记：空白不能提交；提交中禁用按钮；保存失败保留文字。保存过程中继续输入，不应被成功回调清空；退出登录时清空草稿，避免带入另一个账号。
- 快捷导航：Ctrl/⌘ K 打开，方向键选择，Enter 执行，Esc 关闭；中文输入法回车选词不执行；搜索关键词进入备忘录并清除旧文件夹/标签筛选。对未保存备忘录继续使用原有保存保护。
- 手机端（约 390px）：首页单列，快捷入口两列；导航抽屉正常滚动，随手记输入框不溢出。
- 切换夜间模式、系统“减少动态效果”，检查文字对比度和焦点可见性。当前自动化只覆盖逻辑与结构，未替代真实浏览器视觉验收。
