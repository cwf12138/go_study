## 已实现的适配

`mobile/src/mobile-ux.js` 实现原生客户端导航与编辑行为，由 `mobile/src/native-entry.js` 装载；样式在 `mobile/src/mobile.css`。

1. 底部「今天、日历、待办、记录、全部」，全部功能可搜索，包含原有 24 个页面；设置、连接、主题也可直接进入。
2. 非今天页收起重复的顶部信息卡，减少页面头部占位；修复设置图标显示。
3. 备忘录编辑区独立铺满可用高度，保存位于标题栏；预览、置顶、关联待办、导出、复制、归档和回收站操作放入更多菜单；返回键先回列表。
4. 监听实际可视高度，键盘弹出收起底栏并调整弹窗 / 编辑区；Android 使用 `adjustResize`。
5. 收藏页横向溢出和窄屏专注计时盘溢出已修复，日历月视图减少留白，输入控件字号调整。
6. 文件快传增加直接上传 / 发文字入口，跨设备地址使用当前选择的服务器，通过原生剪贴板复制；手机提示与实际 8 MiB 上传限制一致。
7. 天气补齐前台粗略 / 精确定位权限声明，沿用原有主动定位时的系统授权，不申请后台定位。
