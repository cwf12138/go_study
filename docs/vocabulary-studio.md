# 单词学习页 · 学习优先

## 本次调整

- 移除“添加单词”和“创建词书”表单，以及词库列表里的逐词删除按钮。不是删除数据，现有自建词书依然能选用；后端管理接口和英语精读生词保存不变。
- 主体是“我的词书 + 学习卡片”，词书目录和词库浏览位于下方折叠区。点击顶部“选择 / 安装词书”展开目录。
- 安装完成后自动选中词书。已完整安装的词书按钮改为“开始学习”，无需重复安装。未选择有效词书时，优先选内置来源词书；上次选择按账号保存在当前浏览器。
- 放大单词、音标、释义、例句和拼写输入，适配手机和夜间模式。词库浏览每页 20 条，搜索、阶段筛选和翻页不重新加载学习队列。
- 只在当前单词或模式改变时清空拼写；后台刷新不会清空同一单词的未完成答案。快速切书及筛选只接受最新响应。
- 评分期间锁定评分与切书，避免双击重复请求。反馈保存后立即移出旧卡片，再拉取下一词；拉取失败显示“反馈已保存”，不再次提交旧卡片。网络错误导致保存结果未知时，先刷新学习核对记录再继续。

## 统计与边界

- “本批待学”是当前队列数量，最多 100 个；不是词书全部未学量，也不是全天任务总量。
- “今日练习次数”按后端反馈次数统计，不等于不重复的单词数；统计日沿用现有服务端 UTC 日期。
- 每日新词限额与复习调度不变。队列空可能意味着达到了新词限额，或尚未到旧词复习时间，不再一概宣称整本词书已经学完。
- 单词数据仍来自已有本地词书资源。本次未增加在线词典、AI 翻译或新的词书来源。
- 本次仅调整前端，无新增服务或环境变量。正常刷新页面即可加载；若仍运行旧版且缺少此前新增模块的 API，需另外重启 Go 服务。
