# 顶栏天气

登录后，所有模块的公共顶栏都显示天气入口。点击小组件，搜索城市并选择结果，或者点击“使用当前位置”主动授权定位。城市保存在当前浏览器，刷新页面后仍会使用该位置；不会自动猜测用户城市。

小组件展示温度、天气图标和城市，详情包含体感、湿度、风速、最高/最低温度以及当地数据时间。支持夜间主题和窄屏布局。天气采用 Open-Meteo 模型数据，不是逐秒更新的本地传感器测量。

## 更新与故障排查

- 页面可见时每 15 分钟更新；回到页面和恢复联网时检查刷新。手动刷新仍可能命中服务端 15 分钟缓存。
- 获取失败时显示明确错误。如果保留上次数据，会标注“更新失败”，不伪装成最新数据。
- 若显示“天气接口不存在”，停止旧 Go 进程后重新运行 `go run ./cmd/api`。只刷新网页无法为旧后端增加接口。
- 定位需浏览器授权以及 HTTPS 或 localhost。不授权也可手动搜索城市。
- 中文搜索无结果时可尝试拼音或英文城市名称。
- 服务器需能访问 `api.open-meteo.com` 和 `geocoding-api.open-meteo.com`。无法联网会影响天气，但不会影响其他模块。
- 服务端有 10 秒超时、响应大小限制、经纬度验证及最多 128 项缓存。接口需要登录；不修改业务快照或用户学习数据。

## 数据来源与使用范围

[天气 API](https://open-meteo.com/en/docs) · [城市搜索 API](https://open-meteo.com/en/docs/geocoding-api) · [使用条款](https://open-meteo.com/en/terms)

当前接入无密钥公共接口，适用于个人非商业使用。商业部署需核对供应商最新授权、调用限制并切换相应付费服务。经纬度通过 Go 后端转发给供应商；定位取三位小数，不保存到业务快照。
