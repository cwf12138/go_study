# 文件快传

用于电脑、手机等设备通过同一台 Daynest Go 服务收发文件。不是公网网盘、P2P 直连、免登录分享或云同步，也不提供穿透、发现设备或自动配置防火墙。

「随手白板」导航、页面和专用前端资源已移除，原有白板数据、快照、个人 JSON 导出与兼容 API 保留；旧入口返回「今天」。本次没有删除实际用户数据。

## 怎么使用

1. 重启 Go 服务并刷新网页，从侧栏「记录 → 文件快传」进入。
2. 点「选择文件」（支持多选），或将文件拖进上传区，文件会逐个上传。每次选择的有效期会固定在对应任务上：24 小时、7 天或长期保留。
3. 文件显示「已保存」后，在另一台设备的浏览器打开同一台电脑上的服务，**登录同一账号**，进入文件快传，点击下载。其他账号看不到这些文件。
4. 当前页可见、没有正在上传/下载时，每 20 秒自动刷新文件列表，也可手动刷新。用户看到的上传进度到 99% 仍不代表已保存，须等待服务端确认。

「在另一台设备打开」显示电脑的私有 IPv4 候选地址，可复制或手动复制。电脑和手机需要在同一可信局域网，服务必须允许局域网监听，防火墙允许相应端口。候选可能包含虚拟网卡，不保证连通；`localhost` / `127.0.0.1` 在手机上指手机自身，不是电脑。未发现地址时请查看电脑的局域网 IP，手动输入协议、IP 与端口；登录后再从侧栏进入文件快传。

### 开发默认秘钥保护

如果仍使用公开的开发默认 `JWT_SECRET`，文件快传接口只接受本机回环连接，其他设备会收到明确的 403 提示。请自行设置足够强、独立随机的 `JWT_SECRET` 并重启服务、重新登录，再允许局域网访问。这里不自动修改环境变量、网络或防火墙。保护只识别已知默认值，**不评估自定义秘钥是否足够强**；不要把应用暴露到公网，也不要把反向代理到回环地址当成安全部署方案。

普通 HTTP 不加密登录信息、令牌或文件；仅在可信网络使用，不适合敏感资料。需要安全传输时，应自行正确配置 HTTPS，再使用 HTTPS 地址。登录令牌只放在请求头，地址复制不含令牌或文件下载凭证；下载地址不能免登录分享给其他人。

## 文件与任务管理

- 上传队列最多保留 20 项，单个文件最多 **32 MiB**（33,554,432 字节），每账号最多 **256 MiB / 100 个文件**，含过期文件与回收站。服务器同时处理最多 4 个上传；当前页面逐个上传，繁忙时允许手动重试。不支持文件夹或断点续传。
- 断网、超时或取消的结果可能未确认。刷新会按原标识核对接收结果；也可点击重试，沿用同一个文件、标识和有效期，不会覆盖不同内容或重复保存同一请求。重试会重新传完整文件，不会延长原有效期。页面刷新、关闭或退出账号后，未完成的本地 File 对象不会保留，必要时请先核对已保存列表，再重新选择文件。
- 可下载 / 已过期 / 回收站，支持名称搜索、图片/文档/影音/压缩包分类、时间与大小排序、每页 12 个文件。类型仅按扩展名分组，不是安全识别或真实媒体格式鉴定。
- 过期后暂停下载，**不会自动删除**；移入回收站也仍占空间。可恢复，已过期则还需「延长 7 天」才能下载。延长是从操作时刻重新计算七天，不是累计七天；永久文件不显示延长操作。
- 只有过期或回收站文件才能「永久清理」。操作会再次确认，并删除文件内容和记录，**无法恢复**。清理前请确认其他设备已保存所需文件。
- 下载以附件和二进制类型返回，不在应用内执行/预览 HTML、SVG 等文件，不进行病毒扫描。浏览器负责保存位置；请检查下载列表，具体手机浏览器可能打开系统保存面板。
- 详情中的 SHA-256 是接收文件时的指纹。下载前不会重新计算哈希，也不保证文件未被本机其他程序篡改；可用本机工具自行核对。缺失或大小异常的文件不提供下载，但其元数据仍计入配额，需核对后移入回收站并清理。

## 文件存储与备份

文件存放在 `DATA_FILE` **同级的 `transfers` 目录**。默认是 `data/transfers`；每个账号使用散列后的私有目录，服务生成 `.blob` 和 `.json` 文件名，原文件名不参与路径拼接。内容与元数据独立落盘，不将二进制塞入 JSON 快照。

**原有 `studyflow.json` 快照和个人 JSON 导出不包含快传文件及其元数据。** 需要备份时，请停止服务后一起备份 `DATA_FILE` 和整个同级 `transfers` 目录。只恢复 JSON 快照不会恢复附件；不要直接重命名、移动或编辑内部文件。它们没有加密，操作系统目录权限也不能代替磁盘加密。

上传采用有界流式写入、SHA-256、配额预留、临时文件和原子重命名；重复 ID 核对大小、指纹、名称和初始有效期。已知大小按实际大小预留，未知长度的分块上传按 32 MiB 预留，空间不足时可能拒绝。临时副本会额外占用磁盘空间；常规取消/失败会清理临时文件。断电、崩溃可能留下未索引的 `.upload-*`、`.meta-*` 或孤立 blob，不会自动删除不明文件；需停服、备份后由管理员核对。不可让多个 Go 进程同时写同一附件目录。

## API

所有接口要求 Bearer 鉴权；使用开发默认秘钥时另有回环限制。成功响应 `Cache-Control: no-store`。

- `GET /api/v1/transfers`：文件与配额，包含回收站、过期/缺失标记和服务端时间。
- `GET /api/v1/transfers/info`：私有 IPv4 候选地址与配置提醒，不验证网络可达性。
- `PUT /api/v1/transfers/{id}`：**原始文件字节**，非 JSON 或 multipart。`X-File-Name` 为 UTF-8 文件名的 URL 路径百分号编码，`X-File-TTL` 为 `0|24|168`。ID 为 8–80 个字母、数字、下划线或连字符；浏览器生成随机 32 位十六进制标识。文件名最多 180 个 Unicode 字符，不允许路径分隔符或控制字符。上传接口为已认证请求提供两分钟读取期限，反向代理可能有自己的限制。
- `GET/HEAD /api/v1/transfers/{id}/content`：鉴权下载，支持 Range；不接受 URL 中的令牌。
- `POST /api/v1/transfers/{id}/actions`：严格 JSON `{"action":"trash|restore|extend"}`。
- `DELETE /api/v1/transfers/{id}`：永久清理，仅允许过期或回收站文件。不存在返回 404，客户端可将重试后的 404 视为已经清理。

常见状态：400 输入/操作错误，401 未登录，403 默认秘钥禁止非本机访问，404 当前账号无文件，409 同标识不同内容，410 已过期/回收站，413 配额或大小超限，429 上传/操作繁忙，500 存储或文件系统异常。未识别的失败不当作空列表，前端保留可重试的上传任务。

## 验证与排查

```powershell
go test ./...
go vet ./...
node tools/transfers_ui_smoke.cjs
```

已覆盖：账号隔离、默认秘钥回环限制（不信任伪造转发头）、不可变上传重试、原始二进制与 Range 下载、路径/文件名校验、配额预留、四个上传槽位、取消清理、有效期、恢复/延长/永久清理、重启读取，以及模拟 DOM 下的队列、转义、地址复制降级、下载与账号切换。本机真实 HTTP 测试通过独立客户端上传/下载约 2 MiB 二进制并核对 SHA-256。

真实手机/电脑跨设备联调、浏览器下载保存交互和视觉效果尚未现场验收；自动化不是这些测试的替代。

- 无法连接：检查两台设备是否同网、服务是否运行、IP/端口、监听范围、防火墙；不会替你改这些设置。
- 403 提及默认秘钥：先配置安全秘钥并重启、重新登录，不要绕过检查。
- 上传失败：查看单文件/账号限额、网络、服务磁盘可写与空间；代理环境还需检查代理的正文大小及读取期限。不要直接删内部 blob 来腾空间。
- 过期或回收站仍占空间：这是保留恢复能力的设计；确认不再需要后永久清理。
