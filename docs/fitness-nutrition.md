# 饮食搭配 · 运动日常

更新后正常停止旧服务、重新运行 `go run ./cmd/api`，刷新网页，进入「运动日常 → 饮食搭配」。无需 AI、API 密钥或新增依赖。页面内的推荐使用 Go 提供的原创本地组合，不联网查店铺、价格或营养成分。

## 怎么用

1. 选择「日常均衡 / 训练日搭配 / 减脂友好」、早餐/午餐/晚餐/按需加餐，以及食堂、外卖/到店、便利店或自己搭配。
2. 按需展开忌口，勾选常见过敏原排除项、仅植物性组合，或填写具体食材关键词（逗号分隔）。点击「推荐这一餐」。每次最多给出一个主推荐与两个备选，说明主食、蛋白质食物和蔬果分别是什么，以及怎么选、怎么备注。
3. 点击「换一组」优先展示本次尚未出现的匹配组合。候选较少或已遍历时可能重复，页面会说明，不承诺每次全新。饮食方向影响排序，**不改变忌口硬筛选**，也不保证只有某一种方向的食品。
4. 可以收藏组合、取消后再次收藏；收藏视图同样按当前已应用的条件筛选，每页 6 条。不匹配的收藏没有被删除。复制关键词可用于点单或采购，复制失败时展开文字供手动复制，不自动下单。
5. 点击「安排这一餐」选择日期、适用餐次及备注。每日安排每页 8 条，允许记录不同组合备选，不要求全部吃完；相同组合在同一天同餐次最多保留一项有效安排。可标记已吃、撤销、移入当天回收站、恢复。未来安排不能标记已吃，恢复也不能制造重复安排。

内置 **24 个**原创搭配，覆盖鸡肉/鱼/虾/牛肉/家常瘦肉饭、豆腐与熟豆类植物餐、汤面、保留主食的沙拉、食堂组合、便利店饭团/玉米/豆腐组合，以及蛋奶、豆浆、水果等早餐和按需加餐。自己搭配提供选购组合和安全提醒，不是详细烹饪教程。

页面采用与运动模块统一的暖陶色、谷物色和鼠尾草绿；餐盘只示意食物类别，不表示营养或份量比例。饮食视图使用独立介绍，不重复训练首页的大图和统计。加入手机布局、夜间模式、键盘焦点和减少动态效果样式。

## 筛选与健康边界

- “三分练七分吃”是常见说法，本功能不把它作为可量化比例。训练与饮食都需结合个体情况；减脂友好只是一种搭配思路，不承诺减重效果或速度。
- 不采集体重、BMI、体脂、病史，不计算热量缺口、蛋白质克数或“运动后还可以吃多少”。不推荐断食、跳餐、极低热量饮食、补剂或惩罚式运动；加餐完全按需，不强制。
- 这是一般健康成年人的日常参考，不是医疗、营养治疗或个人减脂处方。未成年人、孕产期、有进食障碍经历或需特殊饮食管理者，应先咨询合适的医生/注册营养师，不用此模块自行减重。具体份量取决于个体需要。
- 常见过敏原标签包括食材及部分常用调味料的**可能涉及**项，不能穷尽全部配料或交叉接触风险；没有标签不等于没有过敏原。严重过敏不能仅依赖筛选结果，必须核实商家和包装标签。植物性标签也须核实汤底、肉末、蚝油等实际配料。
- 自由关键词只做文本匹配及少量同义词扩展，不理解整句。无法识别的词会暂停推荐，不自动忽略；无法满足条件时明确显示无匹配，不放宽忌口。改动筛选后立即收起旧结果，重新推荐后才能选择。
- 偏好默认只在当前页面内存中，**主动点击保存**才写入账号。未保存的偏好刷新会丢失。收藏和用餐安排独立于「今天吃什么」，不改动原功能偏好或旧菜谱。

## 可靠性与数据

所有接口需要登录，按账号隔离；饮食记录单独存入快照 `nutrition` 字段，并纳入个人 JSON 导出及数量统计。旧快照缺少该字段仍可加载，不自动生成个人记录。收藏及安排保留保存时的组合快照；新建安排使用当前推荐库内容，已退库的旧收藏可复制参考但不能新建安排。

沿用原项目周期快照及优雅退出保存：请求成功表示写入内存，并不保证该瞬间已经落盘；强制结束进程可能丢失最近一个快照周期的数据。升级前请单独备份，退出服务请正常停止。本次开发没有修改真实 `data/studyflow.json`。

写入携带 revision，客户端保留一次操作的固定标识及完整请求。响应丢失时禁止继续新写入，恢复栏可导出不含登录令牌的请求，再原样重试或核对服务端；不会盲目重复新增。跨窗口冲突不静默覆盖。原请求只在尚未被后续版本推进时可直接重试，否则需要核对。

待确认请求及安排弹窗草稿仅在页面内存中，刷新前请导出或保留文字。切换账号或退出会清理页面私有状态并忽略旧账号的迟到响应。每账号最多 5000 条饮食记录（含软删除），当前不提供永久删除或系统通知。“已吃”仅是用户自行确认，不判定实际摄入或营养达标。日期按中国标准时间处理。

## 资料来源

一般原则参考 [国家卫健委 2025 年“健康饮食、合理膳食”核心信息](https://www.nhc.gov.cn/sps/c100088/202505/6b7a718abd4848e8a3e98fc561a8858b.shtml) 与 [NHS Eatwell Guide](https://www.nhs.uk/live-well/eat-well/food-guidelines-and-food-labels/the-eatwell-guide/)。前者倡导食物多样、增加蔬果和全谷物等；后者强调从整体饮食中兼顾各类食物，不要求每餐达到完美平衡。组合、示意图与文案为本项目原创，不冒充官方食谱，未转载图片。

## 开发与验收

- `GET /api/v1/fitness/nutrition`：返回当前推荐库 `data.catalog`、本账号所有记录（含软删除）`data.entries` 及 `server_time`。
- `PUT /api/v1/fitness/nutrition/{id}`：保存 preference / favorite / plan。偏好固定标识 `nutrition-preferences`；收藏固定为 `nutrition-favorite-{card_id}`；安排使用独立标识。新建 revision=0，后续提交读取版本。
- 服务端只接受已收录组合标识，拒绝客户端传入伪造的组合内容；备注最多 500 字，排除词最多 120 字，日期为 2000–2100 年。安排适用餐次与未来已吃限制由服务端再次检查。
- 更多字段见 [OpenAPI](openapi.yaml)。
