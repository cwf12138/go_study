# 全局内容搜索

从顶部「搜索内容」打开，也可以在非编辑区域按 `/`，或按 `Ctrl/⌘ + Shift + F`。原有 `Ctrl/⌘ + K` 快捷导航保留。已有其他弹窗时不会叠加搜索弹窗。

## 使用

输入标题、正文、备注或标签中的关键词；260ms 停顿后检索，也可点「搜索」。支持中文与不区分大小写的英文**字面匹配**，空格分隔的最多 8 个词必须全部命中，可以分布在不同字段。不支持语义、拼音、模糊纠错或正则表达式。

- 10 类来源：备忘录、待办清单、学习任务、个人日程、心情日记、物品管家、随手收藏、生活保养、运动日常、学习目标。
- 来源按钮可多选；「全部来源」恢复全选。全部取消会提示选择，不会悄悄扩为全部。
- 可按**更新时间**限定范围（中国标准时间、含首尾日期），按相关性或最近更新排序，选择包含归档记录。
- 左侧显示结果，右侧预览约 180 字命中摘要和标签；关键词高亮。摘要不是完整记录，原文更新后以原页面为准。
- 每页 20 条，支持上下页和键盘 ↑/↓。输入框中按 Enter 可打开已加载的当前结果；点「搜索」则重新检索。
- 备忘录直接打开对应 ID，兼容同名与归档记录；已有未保存编辑会先尝试保存，失败则保留编辑。保养事项打开详情；日程、带日期的运动记录跳到关联日期。其他来源打开所属页面，可复制标题继续查找。
- 自动复制不可用时提供手动复制框。Esc、关闭按钮或遮罩关闭；关闭会取消请求并返回入口焦点。

## 数据边界与隐私

仅搜索当前账号已保存的数据，不发送到 AI、外部搜索引擎或其他第三方。检索不会更改记录，不维护额外索引，无需数据迁移或新依赖。关键词和筛选条件只放在页面内存中；不写入地址栏、不保存本地或服务器搜索历史，退出/切换账号时清空。自建反向代理若配置了请求体日志，应另行关闭此接口的正文日志。

回收站、时光邮局信件（包括封存信）、词库、书籍全文、收藏网页远程全文以及未列出的模块不参与检索。日历只搜索用户保存的个人日程：不展开重复实例，也不重复索引从其他模块汇总的日历条目。保养检索当前备注与保留的最近 100 条完成历史；运动检索已保存的训练模板、周计划、训练/补记、打卡，不含设置项或内置动作库。默认排除备忘录/物品/学习目标的归档项和已取消的学习任务。

局部来源失败会明确标注，其余来源仍可查看；全部失败或超时不会伪装成「没有记录」。检索期间切换账号、关闭或发起新检索，旧响应不会覆盖当前结果。服务采用最多 4 个来源工作协程、3 秒期限和 500 条候选最小堆；总命中数与来源计数仍统计全部匹配结果，分页只展示排序最靠前的 500 条。超过上限请细化条件。

## API

已认证只读接口 `POST /api/v1/search`，响应 `Cache-Control: no-store`。不使用带关键词的 GET URL。

```json
{"query":"备份 照片","sources":["memos","care"],"from":"","to":"","include_archived":false,"sort":"relevance","page":1,"page_size":20}
```

`sources` 省略/空数组表示全部；未知来源报错。可选 `sort=relevance|newest`，页码 1–1000、每页 1–30；超出可展示页数时自动回到最后一页。响应 `data` 包含 `items,total,available,page,page_size,counts,warnings,truncated,query`。`warnings` 为失败的来源键，不含后端内部异常。无效输入 400、未登录 401、全部来源失败 503、超时 504。详见 OpenAPI。

## 更新与验证

静态文件嵌入 Go 程序，需要**重启 Go 服务并刷新网页**，无需修改数据文件。

```powershell
go test ./...
go vet ./...
node tools/content_search_smoke.cjs
node tools/memos_ui_smoke.cjs
```

自动化覆盖认证、账号隔离、AND 匹配、归档/回收站/封存信排除、中国标准时间边界、500 条排序分页、取消和部分失败，以及浏览器无关的高亮转义、筛选、竞态、跳转与复制降级。仍需人工浏览器检查：桌面和窄屏布局、夜间模式、键盘焦点、IME 输入，以及真实数据下各模块跳转。该自动化不替代视觉验收。
