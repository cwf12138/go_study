# 学习任务 · 行动空间

本轮升级仅改变前端交互和样式，不改动任务状态机、后端接口或数据快照。样式位于 `internal/httpapi/assets/task-studio.css`，全部限定在 `#panel-tasks`。

## 使用方式

- 概况显示全部已加载任务中的待开始、进行中、逾期未完成和已完成数量，不随搜索结果变化。
- 搜索覆盖任务名称、说明与标签，忽略大小写，多个空格分隔关键词需同时匹配；支持中文输入法组合输入。
- 状态、优先级与到期条件可组合。到期条件只匹配未完成任务；今天截止包括今天早些时候已经逾期的任务，未来 7 天从当前时刻起算，不包含第 7 天同一时刻。
- 默认智能排序：未完成优先、逾期优先、优先级、截止时间、创建时间。还可按截止、创建时间或名称单独排序；缺失日期放在对应日期排序末尾。
- 每页 8 项，筛选后回到第一页；删除或状态变化使末页为空时自动回到最后一个有效页。当前为客户端分页，减少单次渲染的卡片数，不减少 API 返回的任务数量。
- 点击卡片空白处，或使用「···」按钮展开删除操作；在卡片上按 Enter / 空格也可展开。卡片内的完成、开始等按钮仍保留原生键盘操作。
- 「去专注」只关联任务并预填时长，不自动启动计时；预计时长超过 240 分钟时按专注上限填入，未设置预计时长时使用 25 分钟。已有会话时只打开专注页，不替换任务关联。
- 创建期间锁定表单、防止重复提交；失败保留草稿和筛选，成功清空表单并按最新创建展示任务，避免新任务藏在旧筛选中。

```powershell
node tools/app_sync_smoke.cjs
go test ./...

```

前端测试使用模拟时钟、DOM、账号和网络，不触碰真实数据。覆盖组合筛选、时间边界、稳定排序、分页回退、安全转义、空态、输入法、键盘按钮、专注衔接和提交失败恢复。

当前没有可连接的浏览器，实际视觉验收仍待完成。建议在 1440 / 1024 / 768 / 360 像素宽度检查浅色和夜间模式，重点检查长标题、标签换行、删除展开动画、翻页后的焦点和新建按钮定位表单。

本地源码运行刷新页面即可加载改动；镜像或复制静态目录部署需同步完整资源。数据加载失败时仍遵循全局同步提示：保留上次成功加载的内容，不代表实时数据。
