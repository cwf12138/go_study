# 重要日子

重启 Go 服务、刷新网页，在「今天」找到「重要日子」。首页展示最多三张卡片；点击「管理日子」查看完整列表，不增加侧栏页面。

支持生日、纪念日、计划及其他分类；填写名称、日期即可保存，备注和每年重复按需选择。可以置顶、搜索名称和备注、筛选分类 / 未来 30 天 / 回收站，按日期或创建时间排序，每页 6 条。一次性日期过后显示已过天数；每年重复显示下次日期。置顶优先，未置顶时未来日子优先于过去日子。

日期规则：采用北京时间（Asia/Shanghai）的自然日，不包含今天，不用毫秒倒计时；今天为 0 天。重复周期基于公历，不支持农历。2 月 29 日等待下一个实际存在的闰年日期，不自动挪到 2 月 28 日或 3 月 1 日。未来年份的原始日期之前不生成重复记录。页面可见时每分钟更新显示；不提供后台推送、系统通知或自动创建日历日程。

数据按账号保存在服务器，纳入原有周期 JSON 快照、正常关闭时保存及个人 JSON 导出 `important_days` 字段。兼容没有该字段的旧快照，不迁移或改写其他功能数据。每账号最多 500 条（含回收站）；删除为可恢复的软删除，本版不提供永久清理。请继续备份服务器数据。

保存采用稳定 ID 与版本号：请求失败保留原请求，可以原样重试，服务端识别相同版本的同一请求。版本冲突时保留表单，可「重新载入并核对」后再编辑；不会静默覆盖其他窗口。保存中的表单内容不是自动保存，刷新会丢失尚未提交的草稿。原样重试仅在当前页面会话中保留。

API：`GET /api/v1/important-days`，`PUT /api/v1/important-days/{id}`。均要求 Bearer 登录态，严格校验字段、日期与版本，接口定义见 OpenAPI。回收站字段 `deleted`，置顶字段 `pinned`，每年重复字段 `annual`。

验证：`go test ./...`、`go vet ./...`、`node tools/important_days_smoke.cjs`。新增用例覆盖鉴权、账号隔离、非法日期、版本冲突、原样重试、回收站、快照恢复、个人导出、静态资源、日期边界及旧账号请求失效。测试使用临时数据，不修改实际 `data/studyflow.json`。实际浏览器布局仍需人工验收。
