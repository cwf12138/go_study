# D-10 第一批 · 备忘录离线阅读

交付日期：2026-11-03。本轮提供已确认内容的只读快照，先覆盖备忘录。它与本机草稿、在线编辑器和服务端数据分开，不增加离线写入或自动重放。

## 开始使用

1. 在线登录，打开「备忘录」，点击工具栏「离线阅读」。
2. 开启「保留最近阅读」。当前已打开备忘录的服务端版本会加入阅读库；之后只保留成功打开或成功保存后返回的完整内容。
3. 点击「打开阅读库」。可以搜索标题 / 正文 / 标签，按最近保留、原文更新或标题排序，查看保留时间和原文更新时间，导出 Markdown。
4. 手机窄屏优先显示正文，点击「资料列表」再选择其他内容。阅读界面支持浅色和夜间模式。

开关默认关闭，关闭时不会保留正文。快照只包含明确的备忘录字段，不复制令牌、接口响应中的额外字段、未提交编辑或附件。

## 网页和安卓入口

| 场景 | 如何打开 | 当前边界 |
| --- | --- | --- |
| 网页正常在线 | 备忘录工具栏，或登录卡片下方「查看已保留的离线资料」 | 阅读库使用独立页面，避免影响未保存的编辑器。 |
| 网页断网后刷新 / 关闭浏览器后再打开 | 事先完成准备并收藏同一服务的 `/offline/` 地址 | Service Worker 需要浏览器允许的安全上下文，如 HTTPS 或本机 localhost；不把普通局域网 HTTP 宣称为可离线启动。 |
| 普通局域网 HTTP 网页 | 保持已打开的阅读页继续阅读 | 该地址通常不能注册 Service Worker，不能保证断网后重新启动网页。界面会明确显示准备状态。 |
| 安卓电脑不可达 / App 再次启动 | 连接页「离线阅读已保留的资料」 | 阅读资源随安装包内置，不等待完整功能脚本或登录接口；需要事先在线连接、登录并保留过内容。 |

网页只缓存独立阅读页面和它所需的公开 JS / CSS。主应用首页和受保护 API 不由这个 Service Worker 缓存，也不会在离线时假装在线登录。安卓入口复用已选择的电脑地址，切换电脑后旧阅读界面会锁住。

**重启 Go 服务并刷新网页**后获得新入口。安卓需同步资源并重新构建安装包；已安装旧 APK 不会自动包含这些新文件。本轮只完成前端资源与模拟原生桥验证，没有生成 APK 或进行真机验收。

## 保留与清理规则

- 每个账号 / 服务最多保留最近 20 篇、总计 1 MiB；单篇规范化 JSON 上限 240 KiB。超过单篇限制时不截断内容，设置中提示该篇未保留；达到总量限制时淘汰最早保留的只读快照。
- 相同记录的时间版本比较保留纳秒精度。迟到的旧内容不能覆盖新快照；相同版本出现不同正文时保留原快照并提示核对。
- 在线成功删除 / 移到回收站，或明确读取到该条记录不存在 / 无权限时，会移除对应快照。其他设备上发生、但本机尚未获知的删除或修改，仍可能留在旧快照中，所以始终显示只读及时间标识。
- 已知当前会话过期时清除对应快照和本机身份索引，保留原有编辑区和草稿。显式退出 / 切换账号入口退出时，同样清除此账号快照。普通断线或切换到其他已登录账号时，不把它误认为退出；账号与服务仍隔离。
- 阅读时会再次核对当前本机令牌的摘要与此前在线确认的账号索引，不解析 JWT 声明作为离线身份授权，也不把令牌复制进缓存。切换令牌 / 电脑后立即清空旧 DOM，并在导出、选择或清理前复核。
- 本机索引只表明这台设备曾读取过该账号数据，不代表服务器当前已认证会话。内容保存在浏览器 / WebView 本地存储，没有另加密；不应视为公共设备上的保险库。
- 存储空间不足或记录损坏时保留原快照，提示未更新；不影响已成功完成的在线请求。可以明确关闭并清空后重新保留，不自动破坏本机草稿。

「关闭并清空」只影响此设备此账号的快照；不删除服务端原文、草稿、备份或另一个账号。快照可能被容量淘汰，不能作为备份。服务端仍使用既有周期 JSON 快照，本轮没有改变写盘承诺。

## 实现位置

- `read-cache-core.js`：有界存储、完整内容投影、身份摘要、版本比较与清理契约。
- `read-cache.js`：在线账号接入、开关、成功读取 / 保存后的快照观察、过期和退出处理。
- `offline-reader.html / .js / .css`：独立只读阅读、搜索、排序、Markdown 导出、手机列表展开和主题。
- `offline-sw.js`：只缓存公开阅读界面，范围限于 `/offline/`；不拦截根首页或 API。
- `mobile-client.js`：在连接失败时打开内置阅读 iframe，关闭后卸载内容；离线导出复用原生文件保存通道。

更新阅读界面版本时，需要同步更新 Service Worker 缓存名和三个公开资源的版本参数，避免新旧界面混用。不要把身份信息或 API 响应加入其资源清单。
