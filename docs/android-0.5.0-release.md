# Android 0.5.0 日历优化

日期为 2026-11-13，客户端 0.5.0，versionCode 5，应用 ID `app.daynest.personal`。

## 历史事件

服务器实测无法连接原有维基百科数据源，原有两个接口均依赖该站点，备用内容只覆盖三个日期。本轮增加百度百科历史事件来源，和既有接口并行读取，整体等待上限为 5 秒，先返回可用内容。客户端统一通过当前服务端读取，保留事件来源和条目链接。

成功结果按月日缓存在服务进程内，24 小时后重新读取，空结果缓存 30 秒。来源失效时已有成功缓存仍可使用，客户端提供重试。数据中的 HTML 转为纯文本，来源链接限制为可信 HTTPS 站点。

在线检查覆盖 11 月 13 日、1 月 15 日及 2 月 29 日。百度百科月度数据缺少闰日，因此补充带官方来源的离线精选，界面标明「离线精选」。备用条目依据第十二届奥斯卡颁奖记录整理。[奥斯卡官方记录](https://www.oscars.org/oscars/ceremonies/1940)

## 手机日历

- 移除日历顶部宣传区域，压缩工具栏与日期格，首屏显示完整月历，保留农历、节气、节日与记录圆点。
- 月份标题可打开日期跳转，保留今天及前后翻页，并增加月历左右滑动。
- 新增「日程」视图，分日期展示所选日期起未来 31 天的安排，点击个人日程继续编辑。
- 日视图时间轴适配屏幕宽度，自动滚到首个安排附近，点击空白处按半小时选时新建。周视图保留横向滚动。
- 同时段安排按列并排，全天和跨日安排保留原有覆盖规则。
- 当日安排显示选中日期与数量，黄历可折叠，今日签保留在日历工具栏。
- 已有日程提交记录和离线资料从筛选工具打开。保留版本冲突、原提交恢复及本机草稿流程。
