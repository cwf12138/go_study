# 买点什么 · 轻量购物清单

入口：物品管家 → 买点什么，或“今天”首页的同名卡片。没有新增一级导航。

## 怎么用

1. 输入名称回车即可添加；`牛奶 2盒` 这样用空格分隔的数量会自动拆开。只有名称也可以。
2. 支持一次粘贴最多 30 行；Shift+Enter 换行。名称最多 80 字，数量最多 30 字，备注最多 500 字。
3. 点击名称可以编辑并设为常买。勾选后移入“已买到”，可撤销或再次加入。常买区可一键复购，已有同名待购项时禁用。
4. 购物模式放大文字和勾选按钮、收起输入及常买区；不调用屏幕常亮权限，手机仍可能息屏。
5. 移除、购买和复购提供最近一次操作的撤销。撤销记录只在本次页面保留，不支持多级撤销；移除记录保留在快照及个人导出中，但不展示回收站。
6. “存入物品管家”只打开预填表单，必须再点击保存。默认日常用品分类、价格留空；购物数量原文保留在备注，库存整数数量须自行核对。相同购物条目再次转入时打开已有物品，不自动累加库存，也不产生账目。

## 保存与安全

- 每账号最多 2000 条购物记录（含已买到及移除），复购优先复用最近的同名已购条目，不生成无限购买历史。
- 同名待购去重忽略首尾空格、连续空格和英文大小写。后端写锁内检查，两个窗口同时添加也只有一个成功。不做模糊匹配；“牛奶”和“低脂牛奶”是不同条目。
- 每条记录带版本号，过期修改返回 409，编辑器保留输入。未知结果的原样重试使用同一 ID 和版本，不会重复创建。
- 批量是逐项保存，不是事务。部分失败时，成功项保留，只把失败项及未处理内容留在输入框。先解决错误，再提交剩余内容。
- 刷新会丢失未保存输入与撤销记录，离开页面前有未保存输入警告。退出或切换账号会清空草稿。没有离线自动同步功能。
- 数据进入现有 JSON 快照和个人数据导出，无需新环境变量。不修改已有库存、账目、待办或生产数据文件。

```powershell

```
