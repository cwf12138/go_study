# 成长足迹

侧栏“成长足迹”汇总已完成任务、已完成待办、完成的专注会话、读完书籍和未删除备忘录的创建记录。

支持月份、类型筛选，每页 20 条，按时间倒序排列；时间相同时按稳定 ID 排序。统计包含整个筛选结果的记录数、不同日期数、已完成专注分钟数。点击记录旁的按钮返回相应模块，不是定位到单条记录。

该功能直接查询当前用户的现有记录，不额外存储副本，不修改快照。删除原记录、撤销完成、重新完成等操作会改变结果，它不是不可变审计日志。旧数据没有完成时间的条目不会被推测为已完成足迹。

日期按当前设备的 UTC 偏移分组；此版本不处理历史夏令时变化。多模块读取不是同一个数据库事务，更新期间可能看到短暂的不一致，再次查询即可。

部署后重启 Go 服务，刷新网页即可使用。接口：`GET /api/v1/timeline?month=2026-09&offset=480&page=1`，需要登录。
